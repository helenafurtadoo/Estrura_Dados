# Estrutura de Dados

Repositório criado para armazenar exercícios e implementações desenvolvidos durante meus estudos de **Estrutura de Dados utilizando Java**.

O objetivo deste projeto é colocar em prática conceitos fundamentais relacionados à organização, manipulação e busca de dados, além de desenvolver o raciocínio lógico e compreender o funcionamento das principais estruturas de dados.

## Conteúdos

### Aula 01 — Vetores e Matrizes

Exercícios envolvendo armazenamento, acesso e manipulação de dados utilizando vetores e matrizes.

### Aula 02 — Busca e Ordenação

Implementação e prática de algoritmos relacionados à busca e ordenação de elementos.

### Aula 03 — Listas Encadeadas Simples

Estudo e implementação de listas simplesmente encadeadas, trabalhando com nós, referências e operações sobre a estrutura.

### Aula 04 — Listas Encadeadas Duplas

Implementação de listas duplamente encadeadas, permitindo a navegação pelos elementos em ambas as direções por meio das referências para o próximo e o elemento anterior.

### Aula 05

Conteúdo ainda não adicionado ao repositório.

### Aula 06 — Filas e Pilhas

Implementação e estudo das estruturas de **fila (FIFO)** e **pilha (LIFO)**, explorando operações de inserção, remoção e acesso aos elementos.

### Aula 07 — Deques

Estudo e implementação de **deques (Double-Ended Queues)**, estruturas que permitem a inserção e remoção de elementos tanto no início quanto no final.
